## Avatar réaliste (points 21 à 23) : ce qui est livré

- **Le corps** vient de **MakeHuman**, un logiciel libre sous licence CC0 : libre même dans une appli payante, sans rien à verser. Le script `scripts/avatar_corps.py` le prépare une fois (fichier de 1,3 Mo). L'appli mélange ensuite les morphologies de MakeHuman selon la taille, le poids et la morphologie choisis.
- **Le mouvement** : 19 os tirés du squelette de MakeHuman (CC0 aussi). Le cycle de course suit les amplitudes mesurées en course d'endurance (Novacheck 1998) : la hanche va de 15° en arrière à 45° en avant, le genou plie jusqu'à 90°, le coude reste vers 90°, les bras vont à l'opposé des jambes et le buste penche un peu en avant. Les accessoires (casquette, bâtons, montre, gilet) suivent le geste. Si le téléphone a « réduire les animations » activé, le coureur reste figé en pleine foulée.
- **L'affichage** utilise three.js et expo-gl : le même code tourne sur le web, sur iPhone et sur Android. On fait tourner le coureur au doigt. S'il n'y a pas de réseau la première fois, un message le dit.
- **Il reste à faire de ton côté** : l'essayer sur ton téléphone, dans l'appli installée (Expo Go ou version de test), pour vérifier que l'animation reste fluide. Sur ordinateur sans carte graphique, elle tourne à environ 35 images par seconde.
